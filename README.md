# ☕ Coffee Sales Data Analysis — Excel

## 📊 Project Overview

This project is an **end-to-end sales data analysis project built with Microsoft Excel**, designed to transform raw transactional data into meaningful business insights.

The analysis combines **orders, customers, and products data** to explore sales performance, customer behavior, product characteristics, and geographic trends.

The project demonstrates practical **Data Analyst skills**, including data preparation, data enrichment, Pivot Tables, data visualization, and dashboard development.

---

## 🎯 Business Objectives

The main objectives of this project are to:

* Analyze overall sales performance over time
* Identify the best-performing countries
* Analyze sales by coffee type and roast type
* Identify the top customers based on sales
* Understand customer and product characteristics
* Transform raw transactional data into actionable insights
* Build an interactive and easy-to-understand sales dashboard

## 🗂️ Dataset Structure

The project is organized around three main datasets:

### `orders`

Contains transactional information such as:

* Order ID
* Order Date
* Customer ID
* Product ID
* Quantity
* Customer information
* Country
* Coffee Type
* Roast Type
* Size
* Unit Price
* Sales
* Loyalty Card information

### `customers`

Contains customer-level information including:

* Customer ID
* Customer Name
* Email
* Phone Number
* Address
* City
* Country
* Postcode
* Loyalty Card status

### `products`

Contains product information including:

* Product ID
* Coffee Type
* Roast Type
* Size
* Unit Price
* Price per 100g
* Profit

## 📈 Key Analysis Areas

### Sales Performance

The project analyzes sales performance across multiple years and months, allowing the identification of sales trends and variations over time.

### Geographic Performance

Sales are analyzed by country to identify the strongest markets and compare geographical performance.

### Product Performance

The analysis explores different coffee types, roast types, sizes, prices, and profitability to better understand product performance.

### Customer Analysis

The project identifies the **Top 5 customers by sales**, providing a customer-level view of revenue contribution.

### Loyalty Analysis

Customer loyalty card information is incorporated into the dataset to support potential customer segmentation and behavioral analysis.
